# Domain docs

RushBook is a single-context repository.

## Read before working

1. Read root `CONTEXT.md`.
2. Read the ADRs under `docs/adr/` relevant to the work.
3. Use the domain terms defined in `CONTEXT.md`.

If a required concept is missing, note the gap for `/domain-modeling`.

## ADR conflicts

Never silently contradict an accepted ADR. Explicitly identify the ADR and
explain why the decision may need to be reopened.
